# Chart rules

- Use `components/charts.py` as the shared chart factory.
- Use the configured Carbon categorical and sequential palettes; keep semantic status colors separate.
- Keep important series colors stable via explicit shared maps.
- Fit chart type to the analytical question and label units/axes.
- Avoid arbitrary page-level colors, excessive labels, unnecessary legends/gridlines, and technically correct but redundant charts.
- Do not use semantic red/green for nominal categories.
