# Data-visualization review

Map trend → line, comparison → bar, distribution → histogram/box plot, relationship → scatter, matrix → heatmap, and composition → stacked bar when appropriate. Check axes, units, zero baselines where required, sorting, category order, labels, legend position, and direct labels where helpful. Flag excessive labels/gridlines/legends/colors, overlap, and truncated important categories.

Keep categorical, semantic-status, sequential, and diverging colors separate. Maintain stable colors for important series, use the shared chart factory, and do not use red/green for nominal categories. Penalize charts that are technically correct but do not answer a useful question. Do not rely exclusively on color when another reasonable encoding is available.
