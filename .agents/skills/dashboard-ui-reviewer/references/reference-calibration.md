# Reference calibration

Florence Admin Employee Dashboard (`https://florence-admin-template.multipurposethemes.com/bs5/main/index4.html`) calibrates productive density, modular composition, summary-to-detail flow, and above-the-fold efficiency. Do not copy its Bootstrap cards, shadows, rounded cards, palette, badges, or icon-heavy styling.

The user-preferred Figma dashboard calibrates disciplined grid alignment, shared boundaries, restrained whitespace, minimal card chrome, subtle dividers, quiet typography, secondary actions, neutral surfaces, limited accent color, and a compact light sidebar with an obvious active state. Do not treat its bubble/donut charts as data-viz authority.

Carbon is the implementation and visual-system authority for tokens, behavior, interaction patterns, typography, spacing, surfaces, and accessibility. References calibrate qualities, never screenshot similarity.
