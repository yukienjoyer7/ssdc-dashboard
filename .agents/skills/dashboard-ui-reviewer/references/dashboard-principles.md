# Dashboard principles

- One analytical question per section; do not combine unrelated questions in one undifferentiated module.
- Use summary → explanation → actionable detail → methodology/details.
- Keep technical metadata available but subordinate to the executive view.
- Keep items answering the same question spatially close (proximity).
- Give components with the same role the same appearance and behavior (similarity).
- Prefer familiar dashboard patterns and understandable labels.
- Make one primary action obvious; Reset, Download, and Details remain secondary.
- Use grid, alignment, whitespace, typography, and subtle dividers before adding another card.
- Prefer restraint: neutral surfaces, limited accent colors, near-zero radius, no decorative treatment.
