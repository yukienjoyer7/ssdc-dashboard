# Interaction review

Where stable automation allows, inspect filters for discoverability, current-state visibility, apply/reset behavior, persistence, and empty results. Inspect navigation for understandable labels, reachable destinations, obvious current page, and consistent active state. Inspect tables for scrolling, sorting/filtering when present, downloads, actions, and empty states. Check loading, success, warning, and error feedback. Check labels, action hierarchy, disabled states, visible keyboard focus, and page stability after interaction. Document limitations instead of inventing brittle selectors.
