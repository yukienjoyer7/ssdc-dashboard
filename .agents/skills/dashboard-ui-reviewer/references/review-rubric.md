# Weighted review rubric

Score each category 1.0–5.0 and attach page/viewport evidence. Weighted overall score is the sum of `score × weight` divided by 100.

| Category | Weight |
|---|---:|
| Information hierarchy | 20% |
| Analytical usefulness | 15% |
| Layout & alignment | 15% |
| Information density | 10% |
| Visual consistency | 10% |
| Data visualization quality | 10% |
| Interaction clarity | 8% |
| Typography & readability | 5% |
| Responsive behavior | 4% |
| Accessibility | 3% |

Review information hierarchy as context → primary outcomes → explanation → actionable detail → methodology. Ask what question each metric, chart, and table answers and what decision it supports. Check shared grid lines, gutters, content boundaries, proportions, and alignment. Judge whitespace by useful information per viewport. Inspect component, surface, color, spacing, and interaction consistency. Review charts for question fit, encoding, labels, units, sorting, density, color semantics, insight value, and non-color alternatives. Review controls, navigation, filters, tables, loading/empty/error feedback, keyboard focus, and responsive behavior.

Use 5 for consistently clear and purposeful behavior, 3 for material but localized weaknesses, and 1 for severe systemic failure. Use intermediate scores only when evidence supports them.
